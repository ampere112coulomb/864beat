02 / SYSTEM

動作環境の目安

OS
Windows 11・64ビット版を推奨。Windows 10は対応するエディション／更新状態で利用してください。
CPU・メモリ
4コア以上、メモリ8GB以上を目安に。高解像度の背景動画や大量のノーツを使う場合は余裕のある構成を推奨します。
グラフィック
OpenGLが動作するGPUと最新のドライバー。背景MP4にはハードウェア動画再生に対応したGPUがあると有利です。
エディタ
Microsoft Edge WebView2 Runtime が必要です。動画書き出しには空き容量と同梱の ffmpeg.exe も必要です。

CPU・メモリ・GPUの数値は暫定的な推奨目安であり、最低要件や一定FPSの保証ではありません。譜面の密度、MVの解像度、画面サイズで負荷が変わります。OSの対応範囲はMicrosoftの.NET案内、WebView2の要件はMicrosoftの配布案内も参照してください。

03 / SONG SETUP

曲の入れ方

EXEの横に song フォルダ

ゲーム本体のZIPを展開したら、864 beat.exe と同じ場所に song フォルダを作ります。その中に曲ごとのフォルダを置き、譜面ファイルと素材をまとめてください。

現在の選曲画面では、曲はsong 内の曲フォルダ名順に並びます。フォルダをさらに入れ子にした場合は、song からの相対パス順です。並び順を変えたいときは曲フォルダ名の先頭に番号を付けてください。

864beat/
├─ 864 beat.exe
└─ song/
   ├─ 曲A/
   │  ├─ chart.2d
   │  ├─ music.ogg
   │  ├─ jacket.png
   │  ├─ background.png
   │  └─ movie.mp4
   └─ 曲B/
      ├─ chart.2d
      └─ music.mp3

曲ごとのZIPを入手した場合は、ZIP自体を置かずに展開し、曲フォルダを song の中へ移動してください。曲を追加した後は、選曲画面で F5 を押すと再読み込みできます。

ファイル名の対応

譜面の .2d に書かれた名前と、実際のファイル名を一致させます。次は上の「曲A」の例です。

  • SONG:music.ogg ― 楽曲音源
  • JACKET:jacket.png ― ジャケット
  • BACKGROUND:background.png ― 背景画像
  • MOVIE:movie.mp4 ― 背景動画

ゲームは song 以下の .2d を自動検出します。通常は1曲につき1つの曲フォルダと chart.2d を用意します。カテゴリ別のフォルダを曲フォルダの上に追加しても読み込めます。背景画像・動画を使わない曲は、それらのファイルと指定を省略できます。

04 / HOW TO USE

譜面をつくる

基本の流れ

  1. 01エディタを起動し、新規譜面を作成します。
  2. 02曲名、作曲者、難易度、音源、ジャケットを設定します。
  3. 03タイムラインにノーツを置き、BPMや演出を調整します。
  4. 04テストプレイで確認してから、譜面を保存します。

制作前に

ジャケット正方形の画像を用意してください。

音源と画像譜面を配布するときは、使用素材の利用許諾を確認してください。

演出レーン数やキー配置のほか、BPM、カメラなども設定できます。

05 / EDITOR MANUAL

エディタの使い方・全機能

知りたい項目を開いて確認できます。譜面の作成からテストプレイ、MP4書き出しまでの操作をまとめました。複数レイヤーは開発版の機能です。

01起動・必要なファイル・曲フォルダ

Windows用のエディタZIPを展開してから 864 beat Editor.exe を起動します。EXE・editor.html・同梱ファイル・skin フォルダは、元の配置のまま使ってください。画面が表示されない場合は Microsoft WebView2 Runtime を確認してください。

譜面は .2d 形式です。楽曲ごとにフォルダを作り、.2d、音源、ジャケット、背景画像・動画を同じフォルダに置くと管理しやすくなります。上の「曲の入れ方」に構成例があります。

既存の譜面を読み込むと、SONG に指定された同じフォルダ内の音源を探します。SONG がなく、音源が1つだけの場合は自動選択されます。必要ならエディタの音源選択欄で指定し直せます。

02画面の見方
  • 左側：曲情報、音源、ノーツ種類、ファイルの読み込み・保存。
  • 中央：譜面のノーツレーン、演出レーン、判定線、拍のタイムライン。
  • 右側：プレビュー、選択中のノーツ・イベント、イベント一覧。
  • 下部：再生、現在拍、Undo、ノーツ数、テストプレイ、動画書き出し。

表示中の「ノーツ数」はゲームのオート再生で増える判定数に合わせています。ロングの始点・終点はそれぞれ数え、判定のないガイドは数えません。

03曲情報・難易度・レーン数

曲名、作曲者、譜面デザイナー、難易度、レベル、レーン数、初期BPM・拍子、音源、背景画像、正方形のジャケット、背景動画、音源オフセット、プレビュー範囲を設定できます。

難易度は Easy / Normal / Hard / Expert / Master / SPECIAL、レベルは 0～30（最高30）。レーン数は 3 / 4 / 5 / 6 / 8 / 12 に対応します。難易度ごとにレベル、レーン数、ノーツ、演出、レイヤーなどを持てます。古い譜面の Custom は SPECIAL として読み込めます。

画像・動画・音源のファイル名は、保存した譜面と同じ曲フォルダ内の実ファイル名に合わせてください。ジャケットは正方形の画像を使用します。

04タイムライン・SNAP・拡大縮小

中央の譜面をマウスホイールで拍方向にスクロールし、右ドラッグで移動します。譜面上で Ctrl＋ホイールを使うと、拍の表示倍率を変えられます。ブラウザ画面全体の拡大縮小は無効です。

SNAP はノーツやイベントを置く拍の刻み幅です。1、2、3、4、5、6、8、12、16、24、32分割から選ぶか、「その他」に1以上の整数を入力します。「その他」に固定の上限はありませんが、大きすぎる値は操作しづらくなる場合があります。

判定線の拍が、コピー貼り付けやテストプレイ開始位置の基準になります。

05ノーツの配置と種類

左側で種類を選び、ノーツレーンを左クリックして配置します。配置済みのノーツは操作に応じて選択・削除できます。ロングとガイドは始点と終点を2回クリックして作ります。

  • Normal：通常ノーツ。
  • Hold / Long：長押し系のノーツ。始点・終点や継続部分を確認してください。
  • Damage：ダメージノーツ。
  • Guide：判定のない演出用ライン。通常ノーツの背面に表示されます。

配置後は音源を再生してタイミングを確認し、最後に実際のゲーム画面でテストしてください。

06範囲選択・コピー

Shift＋左ドラッグで範囲を囲むと、複数ノーツや演出イベントを選べます。Ctrl＋C でコピー、移動先の拍に判定線を合わせて Ctrl＋V でまとめて貼り付けます。選択パネルから一括削除・設定変更もできます。

選択したノーツにはSSもまとめて適用できます。速度倍率の意味と設定方法は下の「BPM・BS・NS・SS・拍子」を参照してください。

07ガイド・フィーバー演出

Guide は色、透明度、表示方法（通常・フェード・ライズなど）を調整できます。よく使う色はパレットに保存・呼び出しが可能です。選択したガイドの色や透明度もまとめて変更できます。

Fever は Tabを押しながら範囲を指定して配置します。SNAPに沿って始点・終点を決め、ゲーム側の発光演出を確認してください。

08BPM・BS・NS・SS・拍子の変更

BPM・BS・NS・SIGは演出レーンの空白をクリックしてイベントを追加します。既存イベントの選択・編集は右側の一覧からも行えます。複数選択、コピー貼り付け、削除に対応します。

  • BPM：曲の拍の速さを変更します。音源との同期に関わります。
  • BS：レーン全体のスクロール倍率です。0で停止、負数で逆方向になります。
  • NS：ノーツの見た目の速度倍率です。ノーツ間隔の圧縮・拡大にも反映されます。1～3の変化モードと、変化にかける拍数を指定できます。
  • SS（ソロスピード）：選んだノーツ個々にかける速度倍率です。Shift＋左ドラッグでノーツを選択し、右側の選択メニューで倍率を入力して適用・解除します。範囲は0.01～1000。設定済みノーツにはエディタ上で細い緑の縁とSS値が表示されます。SSは演出レーンのイベントではありません。
  • SIG：拍子を変更します。

SSは選んだノーツだけ、NSは以降のノーツの見た目、BSはレーン全体の流れを制御する設定です。

09カメラ演出

CAMERA は位置 X/Y/Z、CAMERA_ADV は位置に加えて角度 X/Y/Z を指定できます。変化モード1～3と、移動にかける拍数を設定します。0拍なら即時切り替えです。

中央のイベントレーンまたは右側のイベント一覧から選択・編集し、右側プレビューとテストプレイの両方で見え方を確認してください。

10レーン・UIの表示切り替え

文字入力中でないときに← / →を押すと演出レーンのページが切り替わり、通常の BS / CAMERA / BPM / SIG と、LANE / UI / NS の設定レーンを表示できます。ノーツを置くレーンは消えません。

LANE はレーンの背景・線・小節線を非表示にしますが、ノーツは表示したままです。UI はスコアやジャケットなどの画面表示を切り替えます。いずれも切り替わるまでの拍数を設定できます。

11音源再生とエディタ内プレビュー

Space で再生・停止します。再生速度は 0.5 / 0.75 / 1.0 / 1.25 / 1.5 倍から選べ、BGMとノーツSEの音量も調整できます。

右側のプレビューでは全レイヤーのノーツが重なって流れ、プレビュー用ノーツ速度は 0.5～10 倍です。実際の判定・描画を確かめるときは F1 のテストプレイを使ってください。

12テストプレイ

F1 で現在の譜面をゲーム本体の描画・判定でテストします。判定線の位置を基準に、開始前にノーツのない8拍の助走が入ります。

テスト中は Esc で終了、R でリトライ、F2 でノーツ速度、F3 でAUTO、F11 で全画面表示を切り替えられます。キー配置はレーン数に応じて変わり、ゲーム側で設定した配列も使えます。

13保存・読み込み・自動復旧

保存ボタンで .2d を保存します。初回は保存先を選び、既存譜面なら上書きできます。音源・画像・動画も曲フォルダにそろえ、ファイル名が譜面内の指定と一致するか確認してください。

クラッシュ時には自動保存データの復旧を提案することがあります。ただし確実なバックアップではないので、編集前後に .2d と素材を別の場所へコピーしてください。Ctrl＋Z のUndoは最大80操作です。

14譜面動画をMP4で書き出す

.2d を開き、難易度を選んで「動画を書き出す (MP4)」を押します。全体または開始拍～終了拍の区間を選び、保存先を指定します。画面録画ではなく、アプリがフレームを生成する方式です。

標準は 1920×1080 / 60fps / MP4（H.264＋AAC）。楽曲音声とオートプレイのノーツSEを収録し、FPS表示は動画に入りません。区間指定時は前後8拍に暗転・フェードイン／フェードアウトを付けます。

書き出しには同梱の ffmpeg.exe、有効な音源、十分な空き容量が必要です。エディタ右側のプレビュー用速度ではなく、ゲーム側の設定が動画に使われます。

15ノーツスキンと素材

EXE横の skin/atlas.png と skin/skin.json でゲーム、テストプレイ、動画書き出しのノーツ外観を変更できます。ファイルを差し替えたらアプリを再起動してください。エディタ中央の簡易譜面表示はスキンと異なる場合があります。

音源・動画・ジャケット・スキンを配布物に含める前に、それぞれの権利者の利用条件を確認してください。

16ショートカット・困ったとき

Space 再生／停止　Ctrl＋Z Undo　Shift＋ドラッグ 範囲選択　Ctrl＋C / V コピー／貼り付け　Ctrl＋ホイール 譜面の表示倍率　← / → 演出レーン切り替え　Tab＋範囲指定 Fever　F1 テストプレイ　F5 選択イベント編集　F11 全画面。

  • 音が出ない：SONG と実際の音源名・保存場所、音量を確認。
  • 画像や動画が出ない：JACKET / BACKGROUND / MOVIE の名前と曲フォルダを確認。
  • テストや動画に反映されない：対象難易度、譜面の保存場所、素材の参照先を確認。
  • エディタ画面が開かない：ZIPを展開し、editor.html と WebView2 Runtime を確認。
17画面フィルター

演出レーンをFILTERへ切り替え、置きたい拍をクリックします。種類はグリッジ・モノクロ・色反転・走査線・発光から選べます。発光は明るい部分を柔らかくぼかして周囲へにじませます。

強度は0～100。瞬時に適用では指定した拍数だけ効果が続き、徐々に変化では指定拍数をかけて目標強度に到達し、次のFILTER設定まで維持します。テストプレイとMP4書き出しにも反映されます。

18複数レイヤー

左側の「レベル」のすぐ下にある編集レイヤーで切り替え、隣の「＋」でレイヤー2以降を追加します。従来の譜面はレイヤー1です。追加数に固定の上限はありません。

レイヤーごとにノーツと BPM・BS・NS・SIG を設定できます。別レイヤーのノーツは中央の編集画面では薄く表示され、右上のプレビューとゲーム中では重ねて流れます。ゲーム中のレーン背景は1つだけ表示します。

別レイヤーの同じレーン・同じ実時間にはノーツを重ねられません。レーンや時刻が異なれば同時に配置できます。FILTER・レーン/UI非表示など画面全体に作用する演出はレイヤー1で設定してください。

レイヤーを含む譜面には、ゲーム v0.5.4 とエディタ v0.6.4 以降を使用してください。
